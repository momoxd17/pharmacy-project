# طب ودواء - صيدلية المجتمع أونلاين

موقع تجارة إلكترونية لصيدلية المجتمع، مستوحى من [United Pharmacy](https://unitedpharmacy.sa/).

## المميزات

- **واجهة عربية كاملة** مع دعم RTL
- **أقسام متنوعة**: أدوية، فيتامينات، عناية بالبشرة، شعر، طفل، أجهزة طبية، وغيرها
- **سلة مشتريات** تفاعلية
- **تصميم متجاوب** للجوال والكمبيوتر
- **عروض وخصومات** مع عرض النسبة المئوية للتوفير

## التشغيل

```bash
# تثبيت الحزم
npm install
cd server && npm install && cd ..

# تشغيل الواجهة والسيرفر معاً (مطلوب للدردشة والملاحظات)
npm run dev:all

# أو بشكل منفصل:
# Terminal 1 - السيرفر (API وقاعدة البيانات)
npm run server
# Terminal 2 - الواجهة
npm run dev

# بناء للإنتاج
npm run build

# معاينة نسخة الإنتاج
npm run preview
```

**ملاحظة:** رسائل الدردشة والملاحظات تُحفظ في قاعدة البيانات فقط عند تشغيل السيرفر (`npm run server`). استخدم `npm run dev:all` لتشغيل الواجهة والسيرفر معاً.

## هيكل المشروع

- `src/pages/` - الصفحات (الرئيسية، الفئات، المنتج، السلة)
- `src/components/` - المكونات (الهيدر، الفوتر، بطاقة المنتج)
- `src/data/products.ts` - بيانات المنتجات والأقسام
- `src/context/CartContext.tsx` - إدارة سلة المشتريات
